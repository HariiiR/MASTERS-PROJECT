# MASTERS-PROJECT

# 🚀 Automated Literature Analysis Pipeline using LLMs

## 📌 Overview

This project presents an **automated literature analysis pipeline** that leverages **Large Language Models (LLMs)** to extract key insights from academic papers. It is designed to streamline the process of reviewing large volumes of research by identifying:

* Research questions
* Key results
* Limitations
* Emerging themes and gaps

Additionally, the project integrates a **knowledge graph** to enhance exploration and discovery of relationships across research works.

---

## 🎯 Key Features

* 🧠 **LLM-Powered Extraction**
  Automatically extracts structured insights (questions, results, limitations) from academic papers.

* 🔗 **Knowledge Graph Construction**
  Builds a citation-based knowledge graph to map relationships between papers and research areas.

* 🔍 **Semantic Search Integration**
  Combines semantic search with graph-based navigation for efficient literature mining.

* 📊 **Research Gap Identification**
  Evaluates model performance in detecting emerging trends and gaps in the **autonomous vehicle domain**.

* ⚡ **Efficiency Boost**
  Reduces manual effort and accelerates literature review workflows.

## 🧩 Methodology

1. **Input Processing**
   Academic papers are ingested and preprocessed.

2. **LLM Analysis**
   LLMs extract:

   * Research questions
   * Results
   * Limitations

3. **Knowledge Graph Generation**

   * Nodes: Papers / Concepts
   * Edges: Citation relationships

4. **Semantic Search Layer**
   Enables contextual retrieval of relevant research.

5. **Evaluation**
   Model performance is assessed in identifying:

   * Research gaps
   * Emerging themes
